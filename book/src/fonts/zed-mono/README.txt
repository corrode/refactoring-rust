Zed Mono 1.2.0 (normal-width Extended family)

Source: https://github.com/zed-industries/zed-fonts
Release: https://github.com/zed-industries/zed-fonts/releases/tag/1.2.0
Archive: zed-app-fonts-1.2.0.zip

These are the original Iosevka-based Zed Mono faces, not the newer Lilex alias.
Regular, bold, italic, and bold italic were converted from TTF to WOFF2
using fontTools with Brotli, without subsetting or changing glyphs.

Files live under book/src so mdBook copies them to the built site.
