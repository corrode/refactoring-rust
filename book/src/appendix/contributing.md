# Errata and reuse

## Reporting a problem

Found a typo, broken link, missed edge case, or trade-off you'd score differently?
[Open an issue](https://github.com/corrode/refactoring-rust/issues/new/choose) with the chapter and your suggested correction.
For code problems, include an input that reproduces the behavior, the result you expected, and what happened instead.

Suggestions about the text belong in issues rather than prose pull requests.
Code fixes and alternative solutions are welcome as pull requests; the repository's [contribution guide](https://github.com/corrode/refactoring-rust/blob/main/CONTRIBUTING.md) explains how to submit and check them.
Adopted suggestions are credited in the [Acknowledgements](acknowledgements.md).
